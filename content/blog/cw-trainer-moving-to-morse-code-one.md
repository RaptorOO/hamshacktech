CW Trainer has a new home. Starting now, it lives at [Morse Code One](https://morsecodeone.com), and everything you've been using comes along for the ride.

## How to move

Go to [Morse Code One](https://morsecodeone.com) and sign in with the same email you used before. That's it. All your data comes over: your progress, your history, and the characters you've been working on.

*Never signed in? Open [CW Trainer](https://hamshacktech.com/cw-trainer/), click the gear icon at the top right to open Settings, and tap "Move my progress to Morse Code One." Then, on Morse Code One, tap "Bring it over."*

## How we got here

About six months into CW Academy, I kept running into the same problem. The usual practice tools were fine for listening, but they were missing things I really wanted. They didn't keep track of which characters I was actually struggling with, and they didn't give me a way to do something about it while I was practicing.

So I set out to create a practice tool around that gap. Instant Character Recognition (ICR) tracks the characters you miss most and lets you drill just those, right in the middle of a session. You hear it, you miss it, you work on it, and you go right back in. It's a full feedback loop instead of just a score at the end. Code Groups works the same way.

Then something I didn't expect happened. My CW Academy study group started using CW Trainer, and they started asking for things. A call sign trainer. Keyer practice. QSO practice. Test prep. A way to see progress over time. A game we could play together. Their requests shaped almost everything you see in it today, and that's how two tools turned into a full set: ICR, Code Groups, Call Signs, Keyer Practice, QSO Practice, Test Prep, My Course, Progress, and multiplayer Morse Code Jeopardy.

## Why a new name

As the tools grew, they outgrew being "a trainer" on a blog. They deserved a home of their own, where everything sits in one place and there's room to keep building. That's Morse Code One.

**Every Tool. One Platform.**

## Free for the people who need it most

Morse Code One is free for new learners and for hams coming back to CW after time away. If you've been meaning to learn the code, or you used to copy 20 WPM and want that back, this is for you.

## There's more coming

This move isn't the finish line. There are many more features on the way, and just like before, a lot of them will come from you. If something's missing, or something could work better, tell me. That's how CW Trainer got good, and it's how Morse Code One will get better.

HamShack Tech isn't going anywhere, either. I'll keep writing here about the gear, the software, and the operating that makes the shack fun, and I'll post Morse Code One updates here as they land.

See you on [Morse Code One](https://morsecodeone.com), and hopefully on the air.
