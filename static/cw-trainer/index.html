Keyer Setup Under development

Plug your key or paddles into a Vail or VBand adapter, plug the adapter into this device, and choose your setup below. No adapter? Use the [ and ] keys or the on-screen pads.

Vail adapter tip: if you’ve used vailmorse.com since plugging the adapter in, unplug it and plug it back in. The Vail site switches the adapter to a mode where it stops sending key presses, and it stays that way until it’s replugged.

    Install the app

      Using a different browser or device?
      • Chrome or Edge (Windows, Mac, ChromeOS, Android): click the install icon at the right end of the address bar, or open the browser menu (⋮ or ⋯) and choose Install / Apps → Install this site as an app.

      • iPhone or iPad: in Safari, tap Share, then Add to Home Screen.
      • Firefox can't install apps — open this page in Chrome or Edge instead. Everything still works right here in the browser tab.
