Keyer Setup

Plug your key or paddles into a Vail or VBand adapter, plug the adapter into this device with USB, and choose your setup below.

Vail adapter tip: if you’ve used vailmorse.com since plugging the adapter in, unplug it and plug it back in. The Vail site switches the adapter to a mode where it stops sending key presses, and it stays that way until it’s replugged.

What's new

    Install the app

    Installed, the CW Trainer gets its own icon and its own window, and it works with no internet connection. Updates arrive automatically whenever you open it while you’re online.

    How to install it

    1. Open the app in Microsoft Edge or Google Chrome (Windows, Mac, ChromeOS, or Android) and click Install app — or the install icon at the right end of the browser’s address bar.
    2. On an iPhone or iPad, open it in Safari, tap Share, then Add to Home Screen.
    3. On a Mac with Safari (macOS Sonoma or later), open it and choose File → Add to Dock.
    4. Launch it from your Start menu, dock, or home screen like any other app.
